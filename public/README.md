# AdamenBlog — оффлайн-версия

Личный блог-портфолио с учебными работами по семестрам.

**Онлайн:** https://adamen-blog.vercel.app  
**GitHub:** https://github.com/paniccaaa/AdamenBlog

## Запуск

**Mac / Linux:**
```bash
bash start.sh
```

**Windows:**
Двойной клик на `start.bat`

Откроется браузер на http://localhost:5173

### Требования

Python 3 (есть по умолчанию на macOS и Linux) **или** Node.js

## Как это работает

- Ссылки на файлы работ ведут на Google Drive (онлайн)
- Если нет интернета — автоматически открываются локальные файлы из папки `works/`
